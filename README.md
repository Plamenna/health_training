# health_training

A small FastAPI webhook server that accepts health data over `POST /webhook`, but only
from callers who send the shared secret in the `X-API-Key` header. Requests without
the header, or with the wrong value, get `401 Unauthorized`.

## Run with Docker

```sh
echo "WEBHOOK_SECRET=$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')" > .env
docker compose up --build
```

With Compose the server listens on <http://localhost:5001> (container port 5000).
Interactive API docs are at <http://localhost:5001/docs>: click **Authorize**, paste
your secret, and you can send test requests from the browser.

Without Compose:

```sh
docker build -t health-webhook .
docker run --rm -p 5000:5000 -e WEBHOOK_SECRET=<your-secret> health-webhook
```

## Verify

With the server running:

```sh
WEBHOOK_SECRET=<your-secret> ./test_webhook.sh
```

Expected:

| Request | Response |
|---|---|
| No `X-API-Key` header | `401` `{"status": "error", "message": "Unauthorized: Invalid or missing token"}` |
| Wrong `X-API-Key` | `401` |
| Correct `X-API-Key`, JSON body | `200` `{"status": "success", "message": "Data received securely!"}` |
| Correct `X-API-Key`, no/empty JSON body | `400` |

Received payloads are printed to the container logs (`docker compose logs -f`).

## Stored data

Each accepted payload is saved as its own Parquet file under
`$DATA_DIR/received_date=YYYY-MM-DD/` (`DATA_DIR` defaults to `data/`, and to `/app/data` in Docker,
where Compose stores it in the `health_data` volume). The body can be one JSON object
(one row) or a list of objects (one row each), and a `received_at` UTC timestamp column is
added. A body that isn't an object or a list of objects, such as `[1, 2]`, gets `400`.
Valid JSON that Parquet can't hold, such as a field that is a number in one record and a
string in another, is kept as-is in `$DATA_DIR/_raw/received_date=YYYY-MM-DD/*.json` so
nothing is lost. Parquet readers skip `_` folders, so it doesn't affect the dataset.

Read everything back as one dataset:

```python
import pandas as pd
df = pd.read_parquet("data")   # the received_date=... folders become a `received_date` column
```

To copy the files out of the Docker volume: `docker compose cp webhook:/app/data ./data`.

To see which variables have arrived, their types, how often each is missing, and sample rows:

```sh
docker compose exec webhook python inspect_data.py   # in Docker
python inspect_data.py data                          # locally
```

## Database (PostgreSQL 18)

Compose also runs a `db` service (`postgres:18`). It needs three more lines in `.env`:

```sh
POSTGRES_USER=health
POSTGRES_DB=health
POSTGRES_PASSWORD=<a long random value>
```

Data lives in the `postgres_data` volume, mounted at `/var/lib/postgresql` (the path Postgres 18
images expect). The port is bound to `127.0.0.1:5432`, so only this Mac can connect:

```sh
docker compose exec db psql -U health -d health    # SQL shell inside the container
```

The schema is in [db/schema.sql](db/schema.sql). Postgres runs it automatically the first time the
volume is created. It is safe to re-run, so apply changes to an existing database with:

```sh
docker compose exec -T db psql -U health -d health -v ON_ERROR_STOP=1 < db/schema.sql
```

| Object | One row per |
|---|---|
| `metric_sample` | metric × hour (or day); key `(metric, ts, source)` removes re-sent duplicates |
| `metric_definition` | metric: frequency and whether a day is its sum or average |
| `sleep_night` | night, filed under the morning you woke up |
| `workout` | workout (the app's UUID); nested segments/splits/events kept as `jsonb` |
| `workout_sample` | workout × series × minute |
| `daily_metric` (view) | local day × metric |
| `daily_summary` (view) | local day: steps, kcal, HRV, resting HR, last night's sleep, workouts |
| `workout_overview` (view) | workout in minutes/kcal; `is_empty` flags 0-minute entries |

Times are `timestamptz`; views group by day in `Europe/Zurich` via `local_day()`.

## Endpoints

- `POST /webhook` — authenticated by `X-API-Key`, expects a JSON body.
- `GET /health` — unauthenticated liveness check.
- `GET /docs` — interactive Swagger UI generated by FastAPI (`/openapi.json` for the schema).

## Run without Docker

```sh
pip install -r requirements.txt
WEBHOOK_SECRET=<your-secret> python server.py              # or: uvicorn server:app --reload --port 5000
```

## Notes

- The secret comes from the `WEBHOOK_SECRET` environment variable; the server refuses to
  start without it. `.env` is git-ignored so real secrets aren't committed.
- The token is compared with `hmac.compare_digest` to avoid timing leaks.
- In Docker the app runs under uvicorn with 2 worker processes as a non-root user.
- The webhook is a plain `def`, not `async def`: writing Parquet blocks, so FastAPI runs
  it in a thread pool instead of stalling the event loop.
- Use HTTPS in front of this (a reverse proxy or tunnel) when exposing it publicly,
  otherwise the API key travels in plain text.
